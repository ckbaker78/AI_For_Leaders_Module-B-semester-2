# 1. Lesson on how to search for Python commands

Let's consider a few possible ways to learn about Python programming.  Let's suppose you want to learn how to produce a short summary of the information in your DataFrame.

1. Your **instructor** could provide the information.

You could be provided with a lesson about functions like info() and describe().  If you have a pandas DataFrame called df, then you can summarize its contents using df.info() or df.describe().  df.info() provides a list of column names with their counts and data types.  df.describe() will provide information such as the mean, min, max, standard deviation, and quantiles.  Thus:

## CELL 4 CODE execution_count=2
df = pd.DataFrame([[1, 4], [2, 5], [3, 6], [4, 7]], columns = ['A', 'B'])
df.describe()

2. You could look up the information on **Google**.

Since there are three intervals here rather than four, it might be more meaningful to ask about a 33rd and 67th percentile rather than 25, 50, and 75.  We can use 1/3 for 0.33 and 2/3 for 0.67 to get the exact percentile values.

## CELL 67 CODE execution_count=34
import matplotlib.pyplot as plt
import pandas as pd

df2['AccountOpened'] = pd.to_datetime(df2['AccountOpened'])

df2['Account Open Month Num'] = df2['AccountOpened'].dt.month
df2['Account Open Month'] = df2['AccountOpened'].dt.month_name()

month_account_counts = (
    df2.groupby(['Account Open Month Num', 'Account Open Month'])[['cd', 'checking', 'savings']]
       .sum()
       .reset_index()
       .sort_values('Account Open Month Num')
)

month_account_counts = month_account_counts.set_index('Account Open Month')

ax = month_account_counts[['cd', 'checking', 'savings']].plot(
    kind='bar',
    figsize=(12, 6), 
    width = .8
)

ax.set_title("Account Types by Month Opened")
ax.set_xlabel("Month Opened")
ax.set_ylabel("Number of Accounts")

for container in ax.containers:
    ax.bar_label(container, label_type='edge', fontsize=8)

plt.xticks(rotation=45)
plt.tight_layout()
plt.show()
